OpsProof v0.1.0: the app for macOS (Apple silicon), Windows (x64) and Linux (x86-64), the reader as one HTML file, the connector for Claude Desktop (opsproof.mcpb), and the engine for Python.

These early builds are not yet signed by Apple or Microsoft; see https://opsproof.systems/download/ for how to open them. Check any file against SHA256SUMS.

Python: pip install opsproof --find-links https://github.com/zmandell-opsproof/opsproof-public/releases/expanded_assets/v0.1.0
