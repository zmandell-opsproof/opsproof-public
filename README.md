# OpsProof downloads

The installers and free tools for [OpsProof](https://opsproof.systems): the app for macOS, Windows and Linux, the reader as one HTML file, the connector for Claude Desktop, and the engine for Python. Each release is under [Releases](https://github.com/zmandell-opsproof/opsproof-public/releases), with a `SHA256SUMS` file to check every download against.

This repository holds downloads only. The Run Record format is specified at [opsproof.systems/docs/spec](https://opsproof.systems/docs/spec/), and anyone may check a Record for free at [opsproof.systems/check](https://opsproof.systems/check/). Nothing you check there is uploaded.
